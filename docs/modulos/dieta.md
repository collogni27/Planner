# Dieta

Não é um contador de calorias diário. É o **registro da versão atual do plano alimentar**, que muda conforme o progresso em kcal.
- **Plano atual:** lista de refeições (adicionar, remover, reordenar, renomear). Cada refeição tem os alimentos **escritos por extenso** (texto livre).
- **Campo de detalhes** do plano (texto livre: meta de kcal, observações etc.).
- **Área de referências livres** (texto e links: anotações, tabelas, fontes).
- **Versionamento:** ao salvar uma alteração, guardar a versão anterior com data, para ver como o plano evoluiu. A tela principal mostra sempre a versão mais atual.
